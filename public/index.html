Multi-Software VPS Safety & Operation Guidelines

Strict rules to prevent downtime across other running services on this server

Active Software & Port Isolation

  • number-portal.softcents.com: Node.js on Port 5000
  • account.softcents.com: Next.js & NestJS on Ports 3000 & 4000
  • smsagri.softcents.com: Go Microservices on Ports 8080-8083

Strict Restrictions

  • NEVER run pkill -f node: It will crash Central Account.
  • NEVER reboot VPS: It takes down all live production software.
  • SAFE RESTART: Use fuser -k 5000/tcp or aaPanel Restart button.
